# X-Ray ASIN Shortlisting Rules

## 1. Objective
The goal is to identify *beatable, high-potential competitor ASINs* from X-Ray data. “Do not chase top sellers — select beatable winners.”

## 2. Hard Filters (Elimination Criteria)
* Remove ASINs with **revenue < $3,000**
* Remove ASINs with **reviews > 1,000**
* Remove ASINs with **rating > 4.7 or < 3.8**
* Remove **very new listings** (low reviews + unstable data)
* **Remove Duplicate Brands**: If multiple ASINs belong to the same brand or parent listing, group them and select only one representative ASIN based on highest ASIN revenue. Remove the rest.

## 3. Ideal Selection Criteria (Sweet Spot)
* **Revenue**: $5,000 – $25,000/month
* **Reviews**: 50 – 300
* **Rating**: 4.0 – 4.4
* Consistent price range within niche

## 4. Niche Health Check
* Prefer niches where multiple ASINs generate $5k–$20k
* Avoid niches dominated by 1–2 ASINs

## 5. Final Output Rule
* Select **8-10 ASINs maximum**
* These must be “replicable competitors” (not perfect, not weak)

## 6. Key Principle
“Do not chase top sellers — select beatable winners.”
